# Projeto de Estruturas de Dados  
* **Árvores (BST, AVL, RB) e Tabela Hash (HashTable)** 
* Projeto desenvolvido no `Windows 11` 
    >pode haver dificuldades de migrar pra linux
## Estrutura do Projeto  
```markdown
/Tree
│── /src         # Implementação das estruturas (.cpp / .impl.h)
│── /include     # Headers das estruturas (.h)
│── /develop     # Códigos de teste/experimental
│── main.cpp     # execução do fluxo
│── Makefile     # Compilação via terminal
```

---

## Como Executar  

### **1. No Visual Studio**  
1. Abra o projeto:  
   - `Tree.sln`
2. Compile e execute:  
   - Pressione **F5** (ou *Debug > Start Debugging*).  

#### 📌 Dependências:  
- Compilador C++17 (já incluso no Visual Studio 2022).

---

### **2. Via Terminal (Windows com MinGW)**  
[`cd Tree`](./Tree/readme.md)

#### 📌 Dependências:  
- **GCC/G++** (MinGW no Windows) ou **Clang**.  
- **Make**


### 3. Pelo executável pre compilado
