# Rodar via Make
este projeto foi feito no windows 11.

## windows

### Rependency
* **Gerenciador de pacotes:** chocolatey
* **Compilador:** cpp [`choco install mingw -y`]
* **Administrador de execução:** make [`choco install make`]

## Run

### Via Terminal - Makefile
| Comando | Descrição |
|---------|-----------|
| `make` | Compila o projeto |
| `make run` | Compila e executa |
| `make clean` | Limpa os arquivos gerados |
| `make package_objs` | Empacota os objetos |
