## Aula 1: Conceitos Básicos (2 horas)

### 1. Gerenciamento de Memória (30 min)
**Ponteiros tradicionais vs smart pointers:**
```cpp
// Estilo antigo (perigoso)
Node* node = new Node();
delete node; // fácil de esquecer

// C++ Moderno (RAII)
std::unique_ptr<Node> node = std::make_unique<Node>();
// Liberação automática
```

### 2. Referências vs Ponteiros (40 min)
```cpp
void modifyByPointer(Node* node) {
    if (node) node->value = 10; // Precisa verificar null
}

void modifyByReference(Node& node) {
    node.value = 10; // Mais seguro, referência não pode ser null
}

// Uso:
Node n;
modifyByPointer(&n); // Passa endereço explicitamente
modifyByReference(n); // Passa implicitamente
```

**Diferenças-chave:**
- Referências não podem ser nulas, ponteiros podem
- Referências não podem ser reatribuídas
- Sintaxe mais limpa com referências
- Ponteiros necessários para polimorfismo

### 3. Containers da STL (30 min)
```cpp
#include <vector>
#include <queue>
#include <stack>

std::vector<int> vec{1,2,3}; // Array dinâmico
vec.push_back(4); // O(1) amortizado

std::queue<Node*> bfsQueue; // FIFO (primeiro a entrar, primeiro a sair)
bfsQueue.push(root);

std::stack<Node*> dfsStack; // LIFO (último a entrar, primeiro a sair)
dfsStack.push(root);

for (auto it = vec.begin(); it != vec.end(); ++it) {
    std::cout << *it << " ";
}
```

## Aula 2: OOP e Árvores Binárias (2 horas)

### 1. Design de Classes (40 min)
**Classe BinaryTree completa:**
```cpp
// BinaryTree.h
#pragma once
#include <memory>
#include <stdexcept>

class BinaryTree {
    struct Node {
        int data;
        std::unique_ptr<Node> left;
        std::unique_ptr<Node> right;
        
        Node(int val) : data(val), left(nullptr), right(nullptr) {}
    };

    std::unique_ptr<Node> root;

public:
    BinaryTree() = default; // Construtor padrão
    ~BinaryTree() = default; // Destrutor padrão
    
    void insert(int value);
    bool contains(int value) const;
};
```

### 2. Construtores/Destrutores (30 min)
```cpp
// Construtor com lista inicializadora
BinaryTree::BinaryTree(std::initializer_list<int> values) {
    for (int v : values) {
        insert(v);
    }
}

// Construtor de movimentação
BinaryTree::BinaryTree(BinaryTree&& other) noexcept 
    : root(std::move(other.root)) {}

// Construtor de cópia
BinaryTree::BinaryTree(const BinaryTree& other) {
    if (other.root) {
        root = std::make_unique<Node>(*other.root);
    }
}
```

### 3. Operações em Árvores (50 min)
**Inserção recursiva:**
```cpp
void BinaryTree::insert(int value) {
    auto insertHelper = [](auto& self, std::unique_ptr<Node>& node, int value) -> void {
        if (!node) {
            node = std::make_unique<Node>(value);
        } else if (value < node->data) {
            self(self, node->left, value);
        } else if (value > node->data) {
            self(self, node->right, value);
        }
    };
    
    insertHelper(insertHelper, root, value);
}
```

## Boas Práticas

1. **Segurança de memória**:
   - Prefira `unique_ptr`/`shared_ptr` a ponteiros crus
   - Use containers (`vector`, `array`) no lugar de arrays estilo C

2. **Passagem de parâmetros**:
   ```cpp
   void readOnly(const Node& n);  // Apenas leitura
   void modify(Node& n);          // Modifica o objeto
   void takeOwnership(Node n);    // Assume posse
   ```

3. **Compilação**:
   - Use `-Wall -Wextra -Werror` para warnings
   - Siga o princípio IWYU (Include What You Use)

4. **C++ Moderno**:
   - Use `auto` para inferência de tipo
   - Prefira algoritmos da `<algorithm>` a loops manuais
