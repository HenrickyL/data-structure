## Aula 1: Fundamentos do C++ Moderno

### 1. Organização de Arquivos em C++
- Separar o código em `.h` (declarações) e `.cpp` (implementações)
- Usar `#pragma once` ou `#ifndef`/`#define` para evitar inclusões múltiplas

```cpp
// arquivo: tree.h
#pragma once

class Tree {
public:
    void insert(int value);
};

// arquivo: tree.cpp
#include "tree.h"
#include <iostream>

void Tree::insert(int value) {
    std::cout << "Inserting: " << value << std::endl;
}
```

### 2. Struct vs Class
- `struct` tem membros públicos por padrão; `class`, privados
- Use `class` para encapsulamento e métodos

```cpp
struct Node {
    int value;
    Node* left;
    Node* right;
};
```

### 3. Tipos Abstratos de Dados (TAD / ADT)
- A interface esconde a implementação interna

```cpp
class Stack {
private:
    int* data;
    int top;
    int capacity;
public:
    Stack(int cap);
    ~Stack();
    void push(int value);
    int pop();
};
```

### 4. Construtores e Destrutores
- Usados para inicializar e limpar objetos

```cpp
Stack::Stack(int cap) : capacity(cap), top(-1) {
    data = new int[cap];
}

Stack::~Stack() {
    delete[] data;
}
```

### 5. Ponteiros vs Referências e uso de `const`
- **Ponteiros (`T*`)**: podem ser nulos, precisam ser desreferenciados
- **Referências (`T&`)**: devem ser inicializadas, nunca são nulas, sintaxe mais simples

**Modificadores com `const`:**
- `const float& x`: referência constante, evita cópia
- `float*`: ponteiro para `float`
- `const float*`: ponteiro para `float` constante
- `float* const`: ponteiro constante para `float`
- `const float* const`: ponteiro constante para `float` constante

```cpp
void modify(int& ref) {
    ref += 10; // altera valor diretamente
}

void modifyPtr(int* ptr) {
    if (ptr) *ptr += 10; // necessário verificar ponteiro
}
```

### 6. Alocação Dinâmica de Memória
- Manual: `new` / `delete`
- Preferencial: `std::unique_ptr` / `std::shared_ptr`

```cpp
int* p = new int(10);
std::cout << *p << std::endl;
delete p;

#include <memory>
auto sp = std::make_shared<int>(42);
```

### 7. Funções e Recursão
```cpp
int factorial(int n) {
    return (n <= 1) ? 1 : n * factorial(n - 1);
}
```

### 8. Tratamento de Exceções
```cpp
void divide(int a, int b) {
    if (b == 0) throw std::runtime_error("Division by zero");
    std::cout << a / b << std::endl;
}

try {
    divide(10, 0);
} catch (const std::exception& e) {
    std::cerr << e.what() << std::endl;
}
```

### 2. Exemplo de Árvore Binária de Busca (ABB)
```cpp
struct Node {
    int value;
    Node* left;
    Node* right;
    Node(int v) : value(v), left(nullptr), right(nullptr) {}
};

class BST {
private:
    Node* root;
    Node* insert(Node* node, int value) {
        if (!node) return new Node(value);
        if (value < node->value)
            node->left = insert(node->left, value);
        else
            node->right = insert(node->right, value);
        return node;
    }
public:
    BST() : root(nullptr) {}
    void insert(int value) {
        root = insert(root, value);
    }
};
```

## Aula 3: Boas Práticas, Smart Pointers e Design de Software

### Boas Práticas e Recomendações
- Use `nullptr`, evite `NULL`
- Use `auto` com tipos evidentes
- Sempre inicialize variáveis
- Use `const` para argumentos que não mudam
- Prefira `unique_ptr`/`shared_ptr` a `new`/`delete`
- Use `range-based for`
- Marque métodos com `override`
- Evite `using namespace std;`
- Separe interface/implementação
- Escreva funções pequenas e coesas

```cpp
std::unique_ptr<int> p = std::make_unique<int>(5);

const std::vector<int>& getData() const {
    return data;
}

class A {
public:
    virtual void speak() const = 0;
};

class B : public A {
public:
    void speak() const override {
        std::cout << "B speaking" << std::endl;
    }
};
```

### Design de Software e Padrões

#### Singleton
```cpp
class Singleton {
private:
    Singleton() {}
public:
    static Singleton& instance() {
        static Singleton s;
        return s;
    }
};
```

#### Factory Method (básico)
```cpp
class Product {
public:
    virtual void use() = 0;
};

class ConcreteProduct : public Product {
public:
    void use() override {
        std::cout << "Usando produto" << std::endl;
    }
};

std::unique_ptr<Product> createProduct() {
    return std::make_unique<ConcreteProduct>();
}
```

#### Strategy
```cpp
class Strategy {
public:
    virtual void execute() = 0;
};

class ConcreteA : public Strategy {
public:
    void execute() override {
        std::cout << "Executando A" << std::endl;
    }
};

class Context {
private:
    Strategy* strategy;
public:
    Context(Strategy* s) : strategy(s) {}
    void run() {
        strategy->execute();
    }
};
```
